{% comment %} Popup que mostra uma foto no tamanho inteiro, sem sair da página. Quem usa: qualquer tela que queira uma foto ampliável. Basta a etiqueta de link em volta da foto trazer o atributo "data-foto" com o endereço da imagem grande, e incluir este arquivo uma vez no fim do conteúdo da página. Funciona sem o popup também, de propósito. O endereço do link é a própria foto e ele abre em aba nova, então: se o Bootstrap não carregar, ou se a pessoa clicar com Ctrl/Cmd ou com o botão do meio, a foto abre numa aba — que é exatamente o outro comportamento aceitável. Nada depende do JavaScript para a foto ser acessível. Sobre comentários neste arquivo: use sempre este formato, com abertura e fechamento em linhas próprias. O formato de uma linha só serve para uma linha só — o tokenizador do Django é compilado sem re.DOTALL, e um comentário que abre numa linha e fecha em outra deixa de ser comentário e vai para a página como texto. Ver seção 9.3 da documentação. {% endcomment %}
